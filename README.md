# invenio-config-tugraz

invenio module that adds tugraz configs.

Override configs from diffrent invenio modules to meet TU Graz requirement:

* Invenio-App
* Invenio-Mail
* Invenio-shibboleth
* Invenio-accounts
* Flask-security
* Defined routes for TUG
